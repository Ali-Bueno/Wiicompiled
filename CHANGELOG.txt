Changelog - Mario Kart Wii Accessibility


Changes on 30/10/2026

New:

Accessibility button in the game's Options. The game's own Options screen, on Mario Kart Wii and on Retro Rewind, has a new last button, "Accessibility", that opens the settings menu. L3+R3 and F8 still open it from any menu.

The settings menu is in submenus: online name first, then steering guide, sound cues, sound, graphics and controls. A enters a submenu, B goes back, and B at the top closes the menu. A submenu says "submenu" after its name.

The F10 bar's settings in the spoken menu. Sound: sound effects, menu sounds and voices volumes, mute the game, mute music while other media plays and mixing audio on a worker thread, beside the volumes that were already there. Graphics: resolution, bloom, display mode, race frame interpolation, copy filter and skipping draws while shaders compile. Controls: the controller on each port, assigning or unassigning one, the GameCube, Classic Controller Pro and PlayStation button layouts, vibration, keyboard and mouse with the WASD layout, a Wii Remotes submenu (use, keep scanning, rescan, calibrate, clear the calibration) and importing controls from Dolphin. Remapping button by button, axis thresholds, the mute shortcut and the FPS counter stay in the F10 bar only.

Fixed:

Branching courses. The course map followed the checkpoints in index order, which is not the lap where the road splits, so on courses like Mushroom Gorge some checkpoints were bound to the wrong stretch and the guide got tangled at those corners. It now follows the game's own checkpoint links.

Changing the online name while the licence settings, licence erase or change Mii screen was open could repaint that screen as if it were the licence list. Only the licence list is repainted now.

The trick ramp rows of the settings menu were spoken in English in every language.


Changes on 21/10/2026

New:

Ledges. A step down onto road beside you (not a fall) is treated like a wall: the racing line keeps clear of it, the edge beeps are unchanged, and "ledge on the left" or "ledge on the right" is said once per stretch. When you drop onto the road below a ledge, the guide and the edge cues follow that lower road until it ends.

Changed:

The trick ramp blip is a little quieter, and it is never in one ear alone.

Fixed:

My kart volume applies from the first moment of each new kart sound; a hop used to start at full volume for one frame.

Retrying the same course starts the race's narration and cues clean. The online name editor accepts the space bar.


Changes on 23/09/2026

New:

Drift and brake in the corner calls. Your engine class changes your speed but not how fast the kart turns, so a corner that holds on the stick at 150cc needs a drift at 200cc and brakes at 500cc. When your kart's speed asks for more than the corner's word already says, "drift" or "brake" is added to the call.

Changed:

Every trick ramp is heard. The ramp blip now finds ramps, jump pads and bouncy mushrooms in the whole course, also those beside the racing line and short ones it used to miss, and it is centred when you are lined up with the ramp, also in a bend. The item box blip got the same centring fix.

Corner words match the stick. The grades are now based on how fast the kart really turns, measured in play, so a "normal" corner takes the stick it is called at. The same corners are called as before. A hairpin names a tight 120-degree shape and no longer implies braking; "brake" says it when it is needed.

Walls and rails standing on the road are seen by the edge cues and by the racing line, which used to see only the edge of the floor.

Courses with a very narrow route in the game data, like N64 Luigi Raceway, no longer spend the first lap without edge cues.

From WiiCompiled 0.2.32: keyboard and mouse support with reworked button remapping, an Exit button, the controller light fix, the mute shortcut fix, a crash fix for Kamek patches such as Retro Rewind's Item Rain, and a fix for flickering overlapping surfaces.


Changes on 16/09/2026

Changed:

Lowered the trick ramp cue by one octave, keeping its short rising jump sound. The race cue and its settings-menu demo use the same lower pitch.


Changes on 14/09/2026

New:

Trick ramp cue. A short rising blip, like an 8-bit jump, points at the next ramp, jump pad or bouncy mushroom you can trick off along the racing line: it gets louder as you approach, like the item box cue, and goes quiet while you are on it. Both this cue and the item box cue now pan in the road's frame, matching the steering guide: on the racing line a ramp ahead is centred, and if you drift right of it your engine sounds right and the ramp sounds left by the same amount. Comes with its own volume row and demo row in the settings menu (trick_ramp_cue_volume in Config.toml). Drop a trick_ramp.wav into accessibility_sounds to use your own sound.


Changes on 12/09/2026

New:

Your name on your Mii. The name the installer asks for (and the new "online name" row in the settings menu) is now carried by a Mii of the mod's own in the game's Mii database, so the licence screen and other players online see it instead of "Player". Renaming a built-in Mii never worked: the game prints "Player" for every one of its six default Miis no matter what they are called.

Online name row in the settings menu. First row of the F8 / L3+R3 menu. Press A, type the name on the keyboard (each letter is read back, Backspace deletes), Enter saves, Escape keeps the old name. Up to ten characters. It is applied at once and the licence screen repaints with the new name; no restart needed.

Update check at startup. Right after "accessibility ready" the game says whether a newer mod version or a newer Retro Rewind is out, and asks: Enter closes the game, runs the installer on your folder and starts the game again; Escape keeps playing. Nothing is downloaded or changed unless you say yes, and a missing network simply says nothing. It needs the installer from this release or later to have run once on your folder. Off with check_updates = false in Config.toml.

Per-cue volume rows. Five new rows in the settings menu, one per cue family: edge, surface (off road / on road notes), curve (entry, apex, exit beeps), countdown (the three rising beeps into a corner) and item box. Each step replays the cue at the new level so you set it by ear. Saved as <cue>_cue_volume in Config.toml and picked up live when you edit the file.

Steering guide calibration rows. At a player's request the guide's three knobs are exposed again: steering guide strength (how far the engine pans at most), anticipation (how far ahead the mod looks: a tenth of a second at 0, the play-tested eight tenths at 100, about a second and a half at 200; it also moves the corner calls and the edge warning) and steering lean angle (how far off the line the kart must point for the widest pan). The defaults are the play-tested values, so an untouched install sounds exactly as before.

Changed:

Smoother steering guide through corners. The racing line's corners are now rounded into arcs before the guide follows it. Before, each corner of the line came through as a sudden lean and a counter-lean right after it, faster than anyone can react from 100cc up; now a bend is one steady lean. On Luigi Circuit the worst kink in the line dropped from about 41 degrees to 18, and the kart's measured wobble at 150cc fell to what it was at 50cc.

Fixed:

The settings menu no longer lets the game navigate underneath it. The port rewrote the pad block every frame, so the menu's block lasted one frame and A or the stick reached the game's own menu while ours was open.

Dialogs read their message. A screen with a message and a button only read the button; now the text is read first, then the focused item. This applies to every dialog, not a list of known ones.

A bad layout pane no longer floods the log every frame: the screen reader's layout walk checks that a pane pointer is mapped before reading it.

Installer:

Asks for your online name on a fresh install, prefilled with the Windows account name; the name shows on a finished install.

Writes the update contract the game reads (installed version, release address, Retro Rewind version file, installer path) and keeps a copy of itself in the install folder, so the in-game update prompt can start it. Accepts --update-mod, --update-retro and --update-all with --launch for that unattended run: the window still opens and logs everything, it just does not wait for a button.

This release can be applied in place: Update in the installer downloads a few megabytes and rebuilds. The build dependencies did not change, so the full installer is only needed for a new install.
